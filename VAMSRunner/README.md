# VAMSRunner

VAMSRunner is a project designed to execute the compiled intermediate language using the VAMS virtual machine. It serves as an example of how to use the VAMS library to run programs.

## Features

- Executes compiled intermediate language files
- Provides performance metrics for parsing, compiling, and execution times
- Demonstrates integration with the VAMS virtual machine

## Getting Started

To get started with the VAMSRunner project, follow these steps:

1. Clone the repository.
2. Open the solution file `VAMS.sln` in Visual Studio or your preferred IDE.
3. Build the solution to restore the necessary packages and compile the projects.
4. Place your compiled `.vams` file in the project directory.
5. Run the `VAMSRunner` project to execute the program.
